# Tasks: Mock Lab REST API (Lab Backend for Automated Clients)

- **Functional Spec:** `functional-spec.md`
- **Technical Considerations:** `technical-considerations.md`

Each slice leaves `mock-lab-app` runnable (`./mvnw spring-boot:run` from `mock-lab-app/`, once Slice 1 is done) with one more piece of the functional spec working end-to-end, and the 46 existing spec-001 tests still green. Every implementation task includes the unit tests for the new logic it adds; the final slice adds acceptance-level tests for the whole spec.

**Verification conventions (used by every Verify task):** API key is the local default `mock-lab-local-token` (`Authorization: Bearer mock-lab-local-token`); start the app on a spare port (e.g. `--server.port=18080`) so it never clashes with a running instance; stop the app and delete any cookie jars / temp output at the end. `mvn` is not on the PATH on this machine — until the wrapper exists (Slice 1), use IntelliJ's bundled Maven (`/Applications/IntelliJ IDEA.app/Contents/plugins/maven/lib/maven3/bin/mvn`); afterwards use `./mvnw`.
